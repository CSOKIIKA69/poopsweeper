### How it works

Click on the tiles to uncover the board. Each number tells you how many 💩 are hiding in the eight surrounding tiles. Use those numbers to figure out where the 💩s are, then flag them with right-click (or a long press on mobile). Reveal every safe tile to win—but uncover a 💩, and it’s game over!
